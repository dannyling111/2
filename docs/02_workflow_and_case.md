# 02 Workflow and Case

## 标准流程（从想法到上线）

### 阶段 0：输入想法
输入示例：`AI 时代，我的工作是 xxx，未来如何工作赚钱？`

### 阶段 1：研究
- 行业趋势
- 用户痛点
- 现有方案
- 付费场景
- 市场缺口

### 阶段 2：机会拆分
候选方向示例：
- 职业诊断工具
- 定制报告
- Prompt 模板库
- 小型课程
- 自动化网站
- 咨询服务
- 社群产品

### 阶段 3：评分筛选
固定 7 维度：
- 痛点强度
- 付费意愿
- 市场增长
- MVP 速度
- 差异化
- 自动化程度
- 个人资源匹配

## 案例结论（本轮）
首个切入建议：**AI 职业赚钱路径诊断网页 + 自动生成报告**。

## 风险与翻转条件
- 目标用户过于宽泛，导致价值主张失焦。
- 第一版系统过重（登录/支付/数据库）拖慢验证。
- 只给结论不给行动步骤，用户感知价值低。
- 没有真实反馈闭环，系统退化为“文档生成器”。
